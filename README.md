# 🩻 دليل وضعيات التصوير الشعاعي | X-ray Positioning Guide

موقع تفاعلي لطلاب الأشعة: تختار الفحص (Chest, Knee, Spine, ...) فيعرض لك **وضعية المريض، اتجاه الأشعة، الديتكتور، نقطة التمركز (CR)، مسافة SID**، وقائمة ما قبل التصوير ومعايير جودة الصورة، مع اختبار قصير لتقيس مستواك. بالعربي والإنجليزي.

> ⚠️ مشروع تعليمي فقط. اتبع دائمًا بروتوكول القسم وتعليمات المشرف.

**المشروع ده مفيهوش تدريب موديل ولا ملفات كبيرة.** كل حاجة بايثون + Streamlit، فالرفع سهل وسريع.

---

## 📁 محتويات المشروع

| الملف | وظيفته |
|---|---|
| `app.py` | واجهة الموقع (الدليل، الاختبار، عن المشروع) |
| `data/exams.py` | **بيانات الفحوصات (16 فحص)** — هنا التعديل والإضافة |
| `diagrams.py` | بيرسم الرسوم التوضيحية (SVG) أوتوماتيك |
| `quiz.py` | بيولّد أسئلة الاختبار من البيانات |
| `translations.py` | كل نصوص الواجهة عربي/إنجليزي |
| `config.py` | إعدادات اختيارية (سطر الاعتماد أسفل الموقع، عدد الأسئلة) |
| `assets/images/` | **صور الـ 3D التوضيحية للفحوصات (16 صورة جاهزة)**، وممكن تستبدلها بصور حقيقية بنفس الاسم |
| `tools/render3d/` | (اختياري) الكود اللي ولّد صور الـ 3D، مش مطلوب للتشغيل |
| `tests/` | سكربتات اختبار للتأكد إن كل حاجة سليمة |
| `.streamlit/config.toml` | ألوان الموقع |
| `requirements.txt` | المكتبات (Streamlit فقط) |

## 🚀 الخطوات

### 1) تجربة الموقع على جهازك (اختياري)
```bash
pip install -r requirements.txt
python tests/validate_data.py   # يتأكد إن البيانات كاملة
python tests/test_app.py        # يجرب الموقع بدون متصفح
streamlit run app.py
```
(Python 3.10 أو أحدث)

### 2) الرفع على GitHub
1. اعمل Repository جديد (Public) على https://github.com
2. ارفع **كل محتويات** الفولدر (بما فيها `.streamlit` و `data` و `assets`) ← **Commit**.
   - تأكد إن فولدر `.streamlit` اترفع (فيه الألوان).

### 3) النشر على Streamlit Community Cloud (مجاني)
1. ادخل https://share.streamlit.io وسجل بحساب GitHub.
2. اضغط **Create app** ← اختر الـ Repository والـ Branch (`main`).
3. **Main file path:** اكتب `app.py`
4. من **Advanced settings** اختر Python **3.11** أو **3.12** ← **Deploy**.
5. استنى دقيقة ويشتغل على رابط عام تقدر تشاركه.

> أي تعديل ترفعه على GitHub بيتحدّث في الموقع أوتوماتيك.

## ✏️ التعديل

**إضافة فحص جديد:** افتح `data/exams.py`، انسخ أي فحص كامل في قائمة `EXAMS`، غيّر `id` وبقية الحقول (عربي وإنجليزي)، وشغّل `python tests/validate_data.py` للتأكد.

**استبدال صورة بصورة حقيقية:** سمّي الصورة بنفس `id` الفحص (مثال: `knee_ap.jpg` أو `chest_pa.png`) وحطها في `assets/images/` مكان صورة الـ 3D، وهتظهر تلقائيًا. لو فحص مفيهوش صورة، الموقع بيرسم SVG بديل. (انتبه لحقوق الصور اللي بتستخدمها وانسب المصدر في التقرير.)

**إظهار سطر اعتماد في أسفل الموقع:** عدّل `FOOTER_CREDIT_AR` و `FOOTER_CREDIT_EN` في `config.py`. فاضيين = مفيش حاجة بتظهر.

## 🛠️ مشاكل شائعة

| المشكلة | الحل |
|---|---|
| `ModuleNotFoundError: data` | تأكد إن فولدر `data` اترفع وفيه `__init__.py` |
| الخط مش ظاهر | محتاج إنترنت لتحميل خط Tajawal، وبيرجع لخط النظام لو مفيش |
| التعديل مش ظاهر في الموقع | اعمل Reboot app من لوحة Streamlit Cloud |
| فشل التشغيل بعد التعديل | شغّل `python tests/validate_data.py` وهيقولك الفحص والحقل الناقص |

## ⚠️ حدود المشروع
المقاسات والمسافات مبنية على المراجع الشائعة وقد تختلف حسب القسم والجهاز. الصور مجسمات 3D توضيحية وليست صورًا طبية حقيقية. الدليل يغطي 16 فحصًا شائعًا فقط.
